# Python 2D Wave Simulation

A 2D wave simulation GPU-accelerated using CuPy (CUDA) for NVIDIA GPUs.

## Prerequisites

- Python 3.x
- NVIDIA GPU with CUDA support
- [CuPy](https://cupy.dev/)
- NumPy / Matplotlib (or whichever display libraries you use)

## How to Run

1. Clone the repository:
   ```bash
   git clone [https://github.com/AnOrangee-T/Python-2D-wave-simulation.git](https://github.com/AnOrangee-T/Python-2D-wave-simulation.git)
   ```
2. Install requirements:
   ```bash
   pip install cupy-cuda12x matplotlib numpy
   ```
3. Run the script:
   ```bash
   python "2D Waves.py"
   ```
